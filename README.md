# ⚽ Maç Analiz AI

Ücretsiz Football-Data.org API + Streamlit ile hazırlanmış ilk sürüm.

## Çalıştırma
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud
1. GitHub'a bu dosyaları yükle.
2. share.streamlit.io üzerinden GitHub ile giriş yap.
3. Repository ve `app.py` dosyasını seç.
4. Deploy et.
5. Uygulamadaki API alanına Football-Data API tokenını gir.

Bu sürüm yalnızca istatistiksel analiz yapar; bahis/tahmin sistemi değildir.
